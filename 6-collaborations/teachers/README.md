# Teachers

這裡放與不同老師、療癒師、顧問或個人品牌合作的長期檔案。

每位合作對象建議保留：

- `profile.md`：老師背景、品牌定位、受眾、服務與合作默契。
- `context/`：對話壓縮、原始脈絡整理、長期可重用的品牌資料。
- `YYYY-MM-project-name/`：單次專案的 README、outputs、working scripts 與 notes。
