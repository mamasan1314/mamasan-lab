## 蠟燭實品方向

參考圖：

- [`hope-light-candles-product-sheet.jpg`](./hope-light-candles-product-sheet.jpg)
- [`hope-light-candles-style-reference.jpg`](./hope-light-candles-style-reference.jpg)

後續生成或設計 Hope Light Moment 蠟燭相關圖片時，請優先符合：

- 小型鋁殼茶蠟，不是大型陶瓷杯蠟燭或柱狀蠟燭。
- 彩色蠟面，可包含粉色、綠色、紫色、黃色、白色。
- 蠟面可有乾燥花草、花瓣、香草、晶石碎片或礦石點綴。
- 可搭配粉晶、紫水晶、綠色礦石、木片底座、粉色背景或儀式小物。
- 對外圖片不要暗示保證招財、桃花、學業、睡眠、醫療或療效結果。
- 若是產品銷售文，最好使用實拍照；AI 圖僅適合當風格提案或接近實品的輔助視覺。
