# Teachers inbox

這裡是老師合作案的**零庫存暫存收件匣**。素材可以先放進來，但每次收件都必須在同一個
工作流程中完成歸檔與清除；正常狀態下，資料夾內只保留本 README。

## 收件即清空 SOP

每次發現新素材時，依序完成：

1. **辨識**：確認來源、所屬老師／專案、素材用途與收件日期。
2. **安全檢查**：若內容含帳號、密碼、token、個資或其他敏感資料，不複製到一般專案
   資料夾，也不把內容寫進 README；依該專案的安全交接規則處理。
3. **重新命名**：用可辨識的英文小寫檔名，包含主題與日期；不要沿用相機或通訊軟體的
   無意義流水號作為正式檔名。
4. **歸檔**：
   - 長期事實／原始參考素材 → 該老師的 `references/`
   - 貼文、廣告、Reels 等製作素材 → 該老師的 `content/` 或專案專屬資料夾
   - 暫時無法判定歸屬 → 移至 `6-collaborations/teachers/_unassigned/YYYY-MM-DD/`，
     不留在 inbox
5. **驗證**：確認目的地檔案存在、可開啟、檔案大小合理；重要素材可再比對 SHA-256。
6. **記錄**：在下方「收件紀錄」留下原檔名、日期、歸檔位置與狀態。紀錄只寫路徑與
   摘要，不寫敏感內容。
7. **清空**：只有在第 5 步通過後才刪除 inbox 原檔。完成時再次確認 inbox 除 README
   外為空。

## 操作原則

- **清空是收件流程的一部分，不是事後定期整理。** 不讓素材在 inbox 過夜或累積到下一批。
- 不直接批次刪除尚未驗證已歸檔的檔案。
- 正式成品不得引用 inbox 路徑。
- inbox 素材與歸檔素材都不等於已核准對外發布；老師／mamasan 完成 QC／QA 後才能作為
  正式交付物。
- 本 README 是 SOP 與收件台帳，永遠保留，不列入「清空」範圍。
