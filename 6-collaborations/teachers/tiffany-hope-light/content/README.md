# Content

這裡放 Tiffany／Hope Light 的對外內容素材，包含 IG 貼文、圖片、Reels、Caption 與發布狀態。

## 內容索引

| 位置 | 用途 |
|---|---|
| [`index.md`](./index.md) | 目前已產出的內容總表與狀態 |
| [`ig-posts`](./ig-posts) | IG 單篇貼文、Caption、封面文字、圖片素材 |
| [`reels`](./reels) | Reels 影片專案、腳本、來源照片與輸出檔 |

## 整理規則

- 可直接對外檢查的素材標成 `ready-to-review`。
- 還需要老師確認故事、價格、規格或療效邊界的素材標成 `needs-review`。
- 舊版氛圍圖不刪除，但只當 mood reference，不作為蠟燭銷售主圖。
- 產品資訊一律回到 [`../product-facts.md`](../product-facts.md) 確認。
