# Hope Light 官網 × LINE 官方帳號一致性檢視報告

- 提供對象：Tiffany／珈語老師
- 檢視日期：2026-08-24
- 檢視方式：網站與 LINE 官方帳號後台唯讀盤點

## 一頁結論

目前顧客可以從 LINE 進入官網購買商品，四張 LINE 商品卡的「了解更多」連結都能開啟正確的官網商品頁，商品頁也能加入購物車。因此，基本購買流程是可用的。

需要優先改善的不是「能不能買」，而是「顧客是否容易找到、看到的資訊是否一致」。目前加入 LINE 後，顧客要先點圖文選單的「希望選品」，再觸發「產品介紹」，看到四張商品卡後才能進官網；LINE 商業簡介與歡迎訊息都沒有直接提供官網購物入口。預約服務的名稱、價格、表單與付款流程也和官網不同，可能讓顧客不確定該以哪一邊為準。

建議先由老師確認三件事：正式服務名稱與價格、商品正式名稱與模式用語、LINE 與官網哪一個是主要成交入口。確認後，再一次同步修改兩邊，會比零散調整更穩定。

## 本次檢視範圍

LINE 官方帳號：

- 商業簡介中的官網資訊
- 加入好友歡迎訊息
- 圖文選單
- 「產品介紹」自動回應與四張商品卡
- 商品卡前往官網的連結

HopeBox 官網：

- 首頁預約表單
- LINE 商品卡對應的四個商品頁
- 商品名稱、描述、價格與加入購物車狀態
- 目前公開的其他預約／課程商品名稱

本次沒有查看客戶聊天內容，也沒有修改網站、LINE 訊息、圖文選單、商品或設定。

## 顧客目前的購買路徑

```text
加入 LINE
  → 點圖文選單「希望選品」
  → LINE 傳送「產品介紹」
  → 顯示四張商品卡
  → 點「了解更多」
  → 進入官網商品頁
  → 加入購物車／結帳
```

判斷：流程可以完成，但入口偏隱藏，而且比直接前往購物頁多一個步驟。第一次加入的顧客不一定知道「希望選品」會觸發商品卡，也不一定知道最終會前往官網購買。

## 目前做得好的地方

- 四張 LINE 商品卡的官網連結都可正常開啟。
- 四個對應商品頁都處於公開且可加入購物車的狀態。
- 官網的預約區可正常開啟，並使用 WooCommerce 結帳流程。
- 網站「老師介紹頁」已有「預約與老師對話」按鈕導向官方 LINE。
- LINE 圖文選單也已有前往官網預約區的「探索服務」入口。
- 兩個現有的 LINE 加好友短連結經確認都指向同一個官方帳號。

## 主要差異與顧客風險

| 項目 | 目前觀察 | 對顧客的可能影響 | 建議 |
|---|---|---|---|
| LINE 商業簡介 | 官網名稱與網址欄位尚未填寫 | 顧客從公開簡介看不到正式網站 | 補上 HopeBox 官網網址與清楚的網站名稱 |
| 購物入口 | 「希望選品」會先觸發「產品介紹」商品卡 | 不容易一眼理解這是官網購物入口 | 改成「官網選購」或「立即購買」，並評估直接連到選品頁 |
| 歡迎訊息 | 有預約說明，但沒有官網或商品入口 | 新朋友可能只看到預約，不知道也能購物 | 加入一個清楚的官網選購按鈕或網址 |
| 預約流程 | LINE 使用外部表單與人工付款說明；官網使用 WooCommerce 結帳 | 同一服務有兩套流程，容易重複詢問或選錯入口 | 決定唯一主要流程，另一邊只保留導流 |
| 預約名稱與價格 | LINE 與官網的服務名稱、組合內容和顯示價格不同 | 顧客可能質疑優惠、內容或付款金額 | 先確認正式方案，再同步兩邊文案 |
| 商品名稱 | LINE 使用「諧和共振機」，官網使用「協和共振機」 | 搜尋、詢問與成交紀錄可能出現兩種名稱 | 由老師確認唯一正式名稱 |
| 模式名稱 | 小貴人、大貴人的部分模式名稱與數量不同 | 顧客無法判斷是否為同一功能 | 建立一份固定模式名稱表，兩邊完全照表使用 |
| 商品價格 | LINE 四張商品卡沒有價格 | 顧客必須逐一進官網才知道預算 | 可顯示價格，或明確註記「最新價格以官網為準」 |
| 官網服務名稱 | 部分公開商品含「改過名／未改名」等內部判別字樣 | 對第一次接觸的顧客不夠直覺 | 改成顧客看得懂的方案名稱，把判別問題放在表單內 |

| 時間 | 120 分鐘 | 120 分鐘 |
| 顯示價格 | 優惠 NT$2,980、原價 NT$3,600 | NT$3,600 |

## 建議執行順序

### 第一優先：先消除成交資訊衝突

1. 統一預約服務名稱、內容、價格與付款入口。
2. 統一「協和／諧和」正式商品名稱。
3. 統一小貴人、大貴人的模式名稱與數量。
4. 將官網公開的內部式方案名稱改成顧客能理解的名稱。

### 第二優先：縮短 LINE 到官網的距離

1. 在 LINE 商業簡介補上 HopeBox 官網。
2. 歡迎訊息加入「前往官網選購」入口。
3. 將圖文選單文字改得更直接，並評估直接連到官網選品頁。
4. 商品卡補價格或「價格以官網為準」說明。

### 第三優先：建立長期同步規則

1. 以一份商品與服務母資料作為名稱、價格、模式和說明的唯一來源。
2. 每次改價、改名或改方案時，同一張工作單同步檢查官網、LINE 歡迎訊息、圖文選單與商品卡。
3. 每季或大型活動前，重新走一次「加入 LINE → 看商品 → 官網結帳」完整顧客流程。

## 建議的完成標準

調整完成後，第一次加入 LINE 的顧客應能在一個畫面內清楚看到「預約服務」與「官網選購」兩條路；同一項商品或服務在 LINE 與官網應使用相同名稱、內容與價格規則，且不需要詢問客服才能判斷哪一邊才是正確版本。
