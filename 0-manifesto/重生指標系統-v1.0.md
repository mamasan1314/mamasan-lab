# 宇宙媽媽賞｜重生指標系統 V1.0

> 內部品牌方法草案。依使用者提供的文字整理；原稿中錯位、無法辨認的表格內容未補寫。這些指標是陪伴過程的觀察線索，不是心理健康量表，也不能單獨證明陪伴造成了改變。

## 核心命題

> 「好了」不是一個終點，是一個方向。你不需要確定她好了，你需要留意她是否正在往自己想要的方向走。

當陪伴者問「她好了嗎」，背後也可能是在問「我的陪伴有沒有幫助」。一個帳號、一支影片或一筆收入，只能表示完成了某項行動；要理解她的進展，還需要聽她如何描述自己的感受、選擇與生活。

## 五個觀察面向

| 面向 | 可以觀察的變化 | 可選的記錄方式 |
| :--- | :--- | :--- |
| 認識自己 | 更能說出自己的情緒、需求與界限。 | 每週覺察日記：記下從「不知道」到「我發現」的具體片段。 |
| 接住自己 | 情緒來時，逐漸能辨認感受，嘗試適合自己的安頓方式。 | 情緒事件記錄：當時發生什麼、她怎麼回應、事後有什麼發現。 |
| 為自己負責 | 開始為自己做決定，並理解選擇的理由與代價。 | 每週記下一個「為自己做的選擇」。 |
| 增加選擇權 | 面對金錢或生活壓力時，逐漸能辨認焦慮，嘗試可承受的下一步。 | 記下她選擇學習、規劃或行動的例子；交易只是原稿提出的一種例子。 |
| 用自己的方式發光 | 更願意表達想法，或用適合自己的方式與人連結。 | 記下從「我沒什麼好說」到「我想說」的表達片段；不以公開發文數量判定。 |

這五個面向可用於一對一陪談、課程回顧或陪伴者自我檢視。記錄時以當事人自己的目標和敘述為準，不把五項都達成當作「好了」的門檻。

## 五個可能的階段

階段用來描述某段時間的狀態，不是固定順序；一個人也可能在不同生活面向處於不同階段。

| 階段 | 她可能說的話 | 可以留意的行為 |
| :--- | :--- | :--- |
| 還在痛 | 「我不知道自己要什麼。」 | 能談到困擾，但暫時難以找到下一步。 |
| 開始看見 | 「我好像有一點感覺了。」 | 開始記錄或說出感受，即使仍然混亂。 |
| 開始接住 | 「我今天沒有像以前那樣失控。」 | 較能辨認情緒，嘗試安頓自己。 |
| 開始選擇 | 「我決定試試看。」 | 做出一個符合自身狀況的決定。 |
| 開始發光 | 「我想把這件事分享出去。」 | 用自己願意的方式表達或支持他人。 |

真正值得觀察的變化，不是從此沒有情緒，而是她更有能力辨認情緒、照顧自己，並在需要時尋求支持。

## 如何回顧陪伴是否有幫助

原稿提出三種可討論的變化。回顧時，請以具體事件和當事人的感受為依據，避免只憑陪伴者的印象下結論。

1. **語言**：她是否更能說出「我想試試看」「我選擇」「我決定」？
2. **行為**：她是否開始詢問自己真正想要什麼，並嘗試一個可行的小步驟？
3. **關係**：她是否更能表達需求與界限，例如「我需要先照顧自己」？

這些是討論進展的線索，不是成效證明。遇到反覆、停頓或退步，也應保留原貌，不把它們當作失敗。
