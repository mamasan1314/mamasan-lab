# 希望之光｜個案紀錄系統工作規格與細項報價 v3（草案）

> 本文件是 [`quotation.md`](./quotation.md) 的技術附件，供製作、審查與專業人員核對。原 NT$45,000 Windows 本機版功能範圍保留，本案一次性合作調整為 NT$20,000；正式欄位、交付條款與實際工作流程仍須確認。改寫層級為 L2。

## 1. 專案目標

把目前的示範稿 v0.8 製作成可長期保存資料的個案紀錄工具，協助 Tiffany：

- 快速找到個案。
- 查看基本資料、來訪歷程、大方向與每次備註。
- 新增、修改及刪除紀錄。
- 找出久未回訪者與當日壽星。
- 保留可攜出的資料，不被單一製作方綁定。

第一版以 Tiffany 本人使用為前提，不按醫院、大型機構或多人企業系統規格製作。

## 2. 示範稿已具備、正式欄位仍待 Tiffany 確認的功能

### 個案搜尋與清單

- 姓名、電話、生日即時搜尋。
- 依來訪日期、多久沒來、來的理由、紀錄類型篩選。
- 顯示照片、姓名、編號、電話、LINE ID、生日、最近來訪與理由。
- 當日壽星提醒；沒有當日壽星時顯示本月壽星。

### 個案資料

- 客戶編號：`139-00001` 起跳的五位數流水號。
- 姓名、電話、LINE ID、生日、性別、職業、宗教信仰、首次來訪。
- 來的理由：感情、事業、親子、金錢、多元，可複選。
- 理由細節與「大方向」自由文字。
- 一位個案可有多次來訪紀錄。

### 每次來訪

- 日期。
- 初評／複評／課程標記。
- 項目、金額與當次備註。
- 新增及刪除單次來訪。
- 呈現方式（v0.7）：每次來訪一列，當次備註與日期、勾選、項目、金額在同一列；打開個案即看到全部來訪的備註，備註超過一行自動往下撐開，不需逐列點開。

### 照片與建檔

- 選擇或拖放電腦上的照片檔案（2026-09-26 起）。原規格含「從電腦相機拍照」；Tiffany 的電腦沒有鏡頭（Darren 轉述），改為只上傳，屬客戶端條件造成的減項，不調整本次價格。
- 新增個案時檢查姓名、電話、生日與 LINE ID 是否可能重複。
- 提醒後仍可由使用者確認建立不同個案。

## 3. 第一版不包含

- 與 WooCommerce 訂單即時同步。
- 自動傳 LINE 訊息或生日祝福。
- 多位員工的角色與分層權限。
- 會計、發票、金流或完整銷售 CRM。
- 醫療診斷、療效判斷或專業法遵文件撰寫。
- 自動把現有紙本資料逐筆輸入系統。

## 4. 方案 A：Windows 本機版

### 運作方式

- 在 Tiffany 指定的一台 Windows 電腦使用。
- 個案資料存於該電腦；照片以檔案保存，其他資料使用 SQLite。
- 不需要網路也能查詢及編輯。
- 提供啟動密碼與閒置自動上鎖。
- 支援全部資料匯出，以及單一個案列印／存成 PDF。

### 加購細項

| 加購項目 | 實際會完成的內容 | 標準分包價 | 首案價 |
|---|---|---:|---:|
| 手機拍照回傳 | 同一 Wi-Fi 下掃 QR code，將手機照片直接放進目前個案 | 8,000 | 5,500 |
| 舊資料匯入 | 提供 Excel／CSV 範本與匯入功能；不含人工輸入紙本 | 5,000 | 3,500 |
| App 自動更新 | 提供新版檢查、更新前備份、失敗回復與更新測試 | 10,000 | 7,000 |

### 備份與還原

- 系統可把資料與照片整理成備份檔，並從備份檔還原。
- 備份位置可指定至外接硬碟或 Tiffany 自己的 OneDrive 資料夾。
- 交付時執行一次備份及還原測試。
- 正在使用中的資料庫不直接放進同步資料夾；只同步已完成的備份檔。

### 手機拍照選配

- 電腦顯示 QR code，手機在同一個 Wi-Fi 下開啟一次性上傳頁。
- 照片傳回目前這一筆個案，手機不保留系統資料。
- 正式納入前，須在 Tiffany 實際使用的電腦、手機與 Wi-Fi 完成測試。
- 若現場網路不允許裝置互連，仍可先用手機拍照，再由電腦選取照片檔案。

### 程式更新選配

- 若需要 App 內自動更新，Windows 版須採正式安裝方式，不採單一免安裝檔。
- 不選自動更新時，以人工更換程式版本處理；資料存放位置不隨程式檔移動。
- 更新前先建立備份；更新失敗時可退回前一版。

## 5. 方案 B：雲端版

### 適用情況

- Tiffany 需要在手機或不同電腦查詢及修改。
- 未來確定有第二位以上的使用者。
- 可接受系統需要網路及持續支付第三方雲端費用。

### 運作方式

- 使用 Tiffany 已有的 `hopebox.com.tw` 網域，可另設子網域，不另購新網域。
- 桌機與手機皆使用瀏覽器開啟。
- 包含登入、忘記密碼、手機版畫面、照片上傳及雲端備份。
- 第一版採線上使用，不包含複雜的離線編輯、雙主檔同步與衝突合併。
- 雲端服務帳號原則上由 Tiffany 或 mamasan 持有，Darren 只取得製作所需權限。

| 個案畫面與搜尋 | 將示範稿正式化，完成新增、修改、刪除、搜尋與篩選 | 22,000 | 15,500 |
| 手機版與拍照 | 手機畫面、個案查詢、修改與照片上傳 | 16,000 | 11,000 |

雲端版 NT$95,000 是 2026-09-21 另建雲端方案的原估參考，**不是**本次 NT$20,000 本機版的加購價或日後固定升級價。若未來由本機移到雲端，須重新估算可沿用成果、資料遷移、登入與權限、部署及持續費用，另案報價。

### 基本安全標準

本案以單人工作室需要的基本保護為準：

- 本機版有啟動密碼、自動上鎖與備份。
- 雲端版使用 HTTPS、獨立登入密碼及服務商提供的基本資料保護。
- 程式、備份與錯誤紀錄不寫入不必要的個案內容。
- 帳號及密碼不得放進 Git、Markdown 或聊天紀錄。

以下不在第一版：企業級單一登入、多層角色權限、自建加密金鑰、全天候資安監控及完整法證稽核。

## 6. 資料與既有 HopeBox 系統的界線

| 資料 | 正式保存位置 |
|---|---|
| 商品、訂單、付款、地址 | 既有 WooCommerce |
| 個案基本資料與來訪紀錄 | 本案個案系統 |
| 網站顧客／訂單看板 | 既有 HopeBox CRM 外掛，維持唯讀 |

第一版不自動合併 WooCommerce 顧客與個案。未來若要串接，優先使用顧客 ID 或經人工確認的匯入流程，不只靠姓名自動合併。

## 7. 使用與個資提醒

- 正式版上線前，由 Tiffany 決定實際需要保留哪些欄位；沒有使用目的的欄位可刪除。
- 若紀錄涉及健康、身心狀態或其他較私密內容，Tiffany 應自行確認已向個案完成適當告知及取得所需同意。
- 本案提供基本資料保護功能，但不代替 Tiffany 的日常保管責任，也不包含法律意見。

## 8. 驗收標準

### 共通

- 能新增、修改、搜尋及刪除個案與來訪紀錄。
- 關閉並重新開啟後，資料仍正確存在。
- 搜尋與進階篩選結果符合輸入條件。
- 重複建檔提醒、壽星提醒與照片功能可正常使用。
- 全部資料可以匯出，單一個案可以列印或存成 PDF。

### 本機版

- 在 Tiffany 指定的 Windows 電腦完成實機操作。
- 完成一次備份與還原演練。
- 若選手機拍照，須在現場 Wi-Fi 完成一次手機上傳。

### 雲端版

- 桌機與手機均可登入及操作。
- 未登入者不能查看個案內容。
- 完成一次雲端備份及還原測試。

## 9. 待確認事項

1. 本案以一台 Windows 電腦的本機版報價；是否需要雲端使用，另案確認與報價。
2. 是否另購手機掃 QR code 拍照。
3. 客戶編號 `139-00001` 是否確定。
4. 久未回訪採 3／6／12 個月是否符合 Tiffany 的工作習慣。
5. 金額欄是否保留。
6. 是否需要匯入既有 Excel／CSV；代為輸入紙本資料另計。
7. 若選本機版，備份要放外接硬碟或 Tiffany 自己的 OneDrive。
