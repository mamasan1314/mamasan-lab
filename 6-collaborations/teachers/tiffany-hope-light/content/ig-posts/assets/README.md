# IG 圖片素材說明

這裡放 Hope Light Moment IG 貼文用圖。素材先不搬動，靠命名區分用途。

## 優先使用

| 命名 | 用途 |
|---|---|
| `*-product-aligned.png` | 接近實品方向的加字版圖片，優先作為對外貼文圖 |
| `*-product-aligned-base.png` | 接近實品方向的無加字或少字版本，可再進 Canva 調整 |

## 保留參考

| 命名 | 用途 |
|---|---|
| `*-base.png` | 早期氛圍圖，主要作 mood reference |
| `hope-light-moment-launch-*.png`，但沒有 `product-aligned` | 早期加字氛圍圖，畫面漂亮但與實品差距較大 |
| `hope-light-moment-001-five-minutes*.png` | 早期單篇五分鐘貼文視覺，可保留作生活覺察方向參考 |

## 發布規則

- 若圖片主角是蠟燭，請優先使用 `product-aligned` 或真實產品照。
- 若對外銷售，最好改用實拍照或與實品高度一致的視覺。
- 圖片上固定露出：`希望之光`、`LINE: @happy139`、`IG: .hopelight.ig / hopelight.moment`。
- 不在圖片上寫保證結果或療效。
