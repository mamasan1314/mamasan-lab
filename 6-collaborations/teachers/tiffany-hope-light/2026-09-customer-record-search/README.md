## v0.2 變更（2026-09-21，Tiffany 追加）

1. **「多久沒來」搜尋**：進階搜尋新增不限／3 個月以上／半年以上／1 年以上。沒有任何來訪紀錄的個案一律算「很久沒來」。搜尋結果每一列也直接顯示「N 個月沒來」，滿三個月轉琥珀色、滿半年轉紅色。
2. **來的理由改為五大類**：`感情、事業、親子、金錢、多元`，取代 v0.1 我自行擬的十個選項。舊選項在載入時自動併入五類（親密關係→感情；工作與事業、生涯方向→事業；親子與家庭→親子；金錢與豐盛→金錢；情緒壓力、睡眠困擾、身體狀況、靈性探索、朋友介紹體驗→多元），細節改由新的「理由細節」自由文字欄承接，不遺失資訊。
3. **重複建檔提醒**：新增客戶時即時比對姓名、電話、生日。
   - 電話或生日撞到既有個案 → 紅色提醒「這一位可能已經建過檔了」，列出是哪一位，可直接「開啟這一位」。
   - 只有姓名相同、電話與生日都不同 → 琥珀色提醒「有同名的個案，先確認一下」。
   - 兩種情況下，第一次按建立只會跳提醒不會建檔；按鈕改成「確認是不同人，仍要建立」，再按一次才真的建立。

已測過：半年以上沒來→1 位、3 個月以上→2 位、親子→2 位；同電話觸發強提醒且第一次按建立被擋下，確認後才建檔。

## v0.3 變更（2026-09-21）

**「來的理由」改為隨時可改。** 紀錄表左上的五類直接是可點的切換鈕，點一下就切換並存檔；下面多一行「理由細節」文字欄，同樣即時存。改完會立刻反映到搜尋，回訪時發現分類要調整不必重建個案。三處用語統一為「來的理由」。

已測過：切換後重新載入仍保留，且該個案立即出現在新分類的篩選結果裡。

## v0.4 變更（2026-09-21）

**基本資料改為可直接編輯，並補上刪除客戶。** 姓名、客戶編號、生日、性別、電話、職業、宗教信仰、首次來訪全部改成點了就能改的欄位，平常看起來仍是紀錄、滑過才露出邊框；年齡與累計次數維持自動計算。姓名或電話改完會同步更新左側搜尋清單。左上角落新增「刪除這位客戶」，會先確認並告知將一併刪除幾次來訪與照片。

打錯字只能整筆重建、誤建的客戶刪不掉，這兩個洞補起來了。

已測過：改名與改電話後重新載入仍保留，且新電話搜得到；刪除後清單減一並自動開啟下一位，重新載入不復原。

## v0.5 變更（2026-09-21，Tiffany 追加）

**拆成「首頁」與「個案頁」兩個畫面。** 首頁放搜尋、進階搜尋與個案清單（照片、姓名／編號、電話、生日、最近來訪與多久沒來、來的理由），點任一位就整頁換成完整紀錄表；個案頁頂端有「← 回搜尋」、目前是第幾位，以及上一位／下一位可以連續翻閱。

順帶把頁尾版本號改成單一來源，之前停在 v0.1 沒跟上。

## v0.7 變更（2026-09-26，Darren 指示）

**來訪紀錄與當次備註合成同一列。** 來源是 Darren 的判斷：Tiffany 應該希望一打開個案頁就看到每次來訪的備註，而不是逐列點開；Darren 本人也說 v0.6 的分開設計他覺得更好，但以老師的使用方式為準。

1. 下半部改成跨整寬的一張表：每次來訪一列，一條底線從日期一路走到備註。左半是日期、初評／複評／課程、項目、金額；右半是當次備註，對齊右上「大方向」那一欄。
2. 備註欄預設約一行高，字多時自動往下撐開，不出現捲軸、不需點開。
3. 項目與金額從右下搬到該列左半，仍可直接點了就改（沿用基本資料「平常像紀錄、滑過才露出邊框」的樣式）。
4. 每列最右側有「刪除」，滑過該列才出現；按一次變成「再按一次刪除」，4 秒內再按才刪。
5. **順帶修正**：Artifact 內 `confirm()` 不會跳出確認視窗、直接回傳 false，所以 v0.4 起線上示範的「刪除這位客戶」與 v0.6 的「刪除這次紀錄」實際上按了沒反應（本機瀏覽器開檔則正常）。兩處都改成上述「按兩次」確認。
6. 窄螢幕（手機）時，同一列改為上下兩行：日期與三個勾選一行、項目與金額一行，備註接在下方。

資料結構不變（仍是每次來訪一筆 `date／initial／follow／course／item／fee／note`），本機儲存鍵與線上 Artifact 資料庫沿用，既有示範資料不會消失。

## v0.8 變更（2026-09-26，Darren 指示三項）

1. **色系改用 `hopebox.com.tw` 官網實際色碼。** 之前的環境擋住官網，v0.6 只能用蠟燭 LP 的色碼代替；這次從公司電腦直接讀到官網。
   - 官網的 Elementor 全站色是出廠預設值（`#6EC1E4` 等），從沒被改過，不是品牌色。
   - 品牌色實際寫在各區塊與外掛樣式裡：首頁最常出現的深紅棕 `#4B1D0D`、預約外掛頁尾的 `#5A210F`／`#4B2117`／`#72574E`、蜜桃底 `#F8ECE6`、奶油 `#FFF8F4`、玫瑰細框 `#D8AFA0`、銅棕 `#A7624D`、密碼頁按鈕 `#4A2416`。
   - 對應：頁面底 `#F8ECE6`、卡片 `#FFF8F4`、主要文字 `#4B1D0D`、次要文字 `#72574E`、強調與按鈕 `#A7624D`（白字對比 4.67，達 4.5 標準）、細框 `#D8AFA0`。其餘深淺是依這幾色推出的中間色。
   - 初評／複評／課程的綠、藍、紫三色是用來區分類型的，保留不動。深色模式也改成同一組暖棕系。
2. **右上「大方向」的格線改到字的下方。** 原本格線從每行字的中間穿過，看起來像刪除線。格線圖樣原本從欄位最上緣起算，而文字從內距以下起算，兩者錯開約半行；現在把格線整張往下移，落在每行字下方約 2px。
3. **照片改成只能上傳。** 原因（Darren 2026-09-26 說明）：NT$20,000 是 Tiffany 專屬特惠價，不含直接拍照；Darren 本來想做的是掃 QR code 用手機拍照同步上傳，那是 NT$5,500 的選配。報價上的「電腦相機拍照」則因她的電腦沒有鏡頭而用不到。「開啟相機拍照」改為「上傳照片」：按「選擇照片」或把照片拖進框裡，一樣從中間裁成 3:4。手機拍的照片要先傳到電腦；iPhone 的 HEIC 格式瀏覽器讀不了，會提示先轉成 JPG。

已看過：v0.8 桌機個案頁一次，另放大確認格線位置。線上 Artifact 同步重發（服務端 Version 9）。
