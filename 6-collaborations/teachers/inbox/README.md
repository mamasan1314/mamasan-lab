# Teachers inbox

這裡是老師合作案的**暫存收件匣**，適合放剛收到、尚未完成辨識與歸檔的原始素材。

## 使用方式

- 新收到的照片、截圖或文件可以先放在這裡。
- 檔名旁若沒有上下文，請在本 README 的「收件紀錄」補上來源、用途與收件日期。
- 素材確認所屬老師與專案後，應複製或移至該老師資料夾內的 `references/`、`content/`
  或專案專屬資料夾；正式成品不要只留在 inbox。
- 不在這裡放帳號、密碼、token 或其他憑證。
- inbox 素材不等於已核准對外發布；老師／mamasan 完成 QC／QA 後才能作為正式交付物。
