### 待修（都在她的帳號裡，Claude 碰不到）

- **Google 預約頁的說明**：LINE ID 前後多了兩個反引號（`` ` ``），是從這份文件舊版的格式一起貼過去的。刪掉即可。
- **Google Meet**：預約頁上沒看到視訊會議。預約設定裡勾「Google Meet 視訊會議」，確認信就會自動附連結；不勾的話，她要自己傳連結。

### 回應設定要確認的一件事

設定 → 回應設定：**「聊天」要開著**。
對方傳「咖啡」「蠟燭」都是進到聊天室，由她本人回；這一版不另設關鍵字自動回應。
如果「聊天」關著、又有預設的自動回應（「很抱歉，本帳號無法個別回覆……」），客人傳「咖啡」會先收到那一句。
