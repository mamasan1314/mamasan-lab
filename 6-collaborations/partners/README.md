# Partners

這裡保存和 `mamasan-lab` 一起建造能力、方法與長期工作關係的夥伴。

這一區不同於 `teachers/`：

- `teachers/` 保存 mamasan 對外承接的老師、品牌與交付案件。
- `partners/` 保存共同實驗、教學、技術引導與能力養成。
- 夥伴可以協助搭架、提問、校準與見證，但不因此取得 mamasan 的品牌、內容或 repo 主權。
