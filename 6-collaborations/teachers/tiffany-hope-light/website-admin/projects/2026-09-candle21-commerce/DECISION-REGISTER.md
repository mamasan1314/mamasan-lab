# 21 顆蠟燭 commerce｜決策登錄

狀態：**給 mamasan QC／QA 的工程草稿，不代表 Tiffany 已核准。**

## 已採用的工程預設

這些預設可讓藍圖與本機實作前進；若 mamasan／Tiffany 不同意，應在施工前改掉。

| ID | 預設 | 理由 |
|---|---|---|
| C21-P01 | LP 提供「直接訂購」與「先諮詢」兩個入口 | 同時服務已確定與未確定選款者 |
| C21-P02 | 先諮詢者在諮詢後才回 WooCommerce 選款結帳 | MVP 不建立「已付款但選款未完成」的半張訂單 |
| C21-P03 | 直接訂購時，十款數量須為非負整數且合計恰好 21 | 避免人工重新確認基本配置 |
| C21-P04 | WooCommerce 是價格、付款、地址、訂單與配置的正式主檔 | 延續 D-001 與 D-003，不造第二本帳 |
| C21-P05 | CRM 維持唯讀，只顯示蠟燭配置、來源與諮詢路徑 | 不擴大後台寫入面與個資風險 |
| C21-P06 | LINE MVP 使用關鍵字自動回應與一般 HTTPS 連結 | 不為首版引入 Messaging API／LIFF 維運負擔 |
| C21-P07 | 每個公開入口使用明確 source code／UTM | 不靠容易遺失的 referrer 猜訂單來源 |
